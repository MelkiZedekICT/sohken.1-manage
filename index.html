QUESTIONS

Plain answers.

Is Sohken a full safety guarantee?

No. It adds a useful check before supported actions. An agent can still be risky if it uses tools outside Sohken.

Does my source code go to the website?

No. Project checks run in the local app. If you select the optional dependency check, Sohken sends npm package names and versions to Google's public OSV service; it does not send source code.

Will I be charged?

No. Sohken Plus checkout is not available. The ₹199 monthly price is a plan under development.

What works today?

The alpha checks supported local code patterns, can optionally look up npm advisories, checks pasted text, and records a narrow set of simulated local actions. It does not control arbitrary agent tools or provide a full security audit.

PRIVACY

Your work stays yours.

This static page does not ask you to create an account or submit an email. Its text demo runs in your browser. Project audits run in the downloadable local app; the optional npm advisory check shares package names and versions with OSV, not source files.

GitHub hosts the release downloads and may process download requests under its own privacy policy. Sohken does not receive your local scan reports.

ALPHA TERMS

Clear limits.

Sohken is an early test build. Pattern checks can miss issues and show false alarms. A clean report is not proof that code or an agent is safe. You remain responsible for review and testing.

This page does not take payment. Paid accounts, shared hosting and customer support are not available yet.
