QUESTIONS

Plain answers.

Is Sohken a full safety guarantee?

No. It adds a useful check before supported actions. An agent can still be risky if it uses tools outside Sohken.

Does my work go to the website?

No. The product runs on your computer. The public page stores only the email you choose to submit.

Will I be charged when I join?

No. The page only records interest. Founder members see the private build before any payment request.

What works today?

The local app can check text, block fixed unsafe actions, ask for approval, and keep a local history. It is an early build.
